# myvpn — VLESS + REALITY (Xray-core)

Устойчивый к DPI/ТСПУ туннель: сервер на Linux, клиент на Windows.

## Почему не «свой протокол»
Любой самописный протокол имеет собственную сигнатуру и блокируется после
первого же анализа. REALITY не имеет собственной сигнатуры: сервер
проксирует TLS-рукопожатие к настоящему сайту (`SNI`), а активные проверки
получают его настоящий сертификат. Клиент имитирует отпечаток Chrome (uTLS),
`xtls-rprx-vision` убирает характерную «TLS-in-TLS» структуру.

## Сервер (Linux, VPS за пределами РФ)
```
sudo ./server/install.sh [порт=443] [сайт-маскировка=www.microsoft.com]
```
Скрипт ставит Xray, генерирует UUID/ключи, запускает сервис и печатает `vless://` ссылку.

## Клиент (Windows, PowerShell)
```
.\client\vpn.ps1 -Link "vless://..." -SystemProxy
.\client\vpn.ps1 -Stop
```
Поднимает SOCKS5 `127.0.0.1:10808` и HTTP `127.0.0.1:10809`.

## Рекомендации
- Порт 443, VPS в хорошей подсети (не из самых известных «VPN-диапазонов»).
- Маскировочный сайт: TLS 1.3 + HTTP/2, не заблокирован, желательно
  географически/по ASN близкий к вашему VPS (проверка: `xray tls ping <host>`).
- Не делитесь одной ссылкой публично; на каждого пользователя — свой UUID.
- Обновляйте Xray-core: методы блокировки меняются.
